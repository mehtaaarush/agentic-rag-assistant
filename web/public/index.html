Method

  1. Ingest

    Each PDF page is read with pypdf and split into 1,000-character chunks with a 200-character overlap: 1,272 chunks in all.

  2. Embed

    Chunks are embedded once with all-MiniLM-L6-v2. Your browser loads the same 8-bit model, 23 MB, to embed the agent’s queries, and ranks chunks by cosine similarity.

  3. Decide

    Gemini runs a ReAct loop with two tools, search_papers and search_web, choosing one, both or several rounds before it answers.

  4. Answer

    The answer may use only what the tools returned and cites the paper and page. Web search uses Google Search through Gemini.

The original command-line tool runs the same pipeline with FAISS and LangGraph in Python. This web version keeps the chunking, the embedding model, the tools and the prompt, and moves retrieval into the browser so the server stays small.
